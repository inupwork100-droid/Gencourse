# Oxford International Primary History 6 — читач

Застосунок для читання підручника англійською з озвученням і перекладом українською.

- ▶ читає текст британським голосом, кожне сказане слово підсвічується жовтим, прочитане стає синім;
- торкнись слова — переклад, вимова, словосполучення й переклад усього речення («Читати звідси» продовжує з цього місця);
- виділи пальцем кілька слів — переклад виділеного;
- EN / EN+UA / UA — весь текст англійською, з перекладом під абзацами або повністю українською; кнопка «UA» біля абзацу перекладає лише його;
- «Мої слова» — збережені слова й тренування «Перевір себе».

Файли: `lesson-1-1.js` — текст уроку з перекладом речень, `dictionary.js` — словник, `app.html` — застосунок, `images/` — картинки зі сторінок.
Зібрати: `python3 build.py` → `index.html` (один файл, працює офлайн у браузері).
Новий урок: додати `lesson-X.js` з тією самою структурою та слова в `dictionary.js`.
