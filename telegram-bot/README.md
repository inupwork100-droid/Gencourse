# Сімейний щоденник у Telegram

Бот живе в групі з гілками (темами). Мама й донька обидві в групі, тож мама бачить усе, що відмічає донька.

| Гілка | Що там відбувається |
|---|---|
| 📅 День | Щовечора підсумок дня: настрій, заняття, оцінки, домашка, звички. У неділю та в останній день місяця підсумок тижня чи місяця |
| 😊 Настрій | Зранку «Доброго ранку, як настрій?», увечері «Як пройшов день?». Смайлики-кнопки, а коментар можна просто написати в гілку |
| 🕐 Розклад і заняття | Вранці план на день, нагадування за 10 хв до заняття, після заняття питання «Як пройшло?» з оцінкою 1–12 і коментарем |
| ⭐ Оцінки і домашка | Кожна нова оцінка, увечері перевірка домашки на завтра по предметах, графік оцінок |
| ✅ Звички | Щоранку список звичок із кнопками, увечері нагадування про невиконані, графік «що прокачалось» |

## Запуск за 4 кроки

### 1. Створити бота
1. У Telegram відкрийте **@BotFather**, надішліть `/newbot`, придумайте назву.
2. BotFather дасть **токен**, наприклад `123456789:AAH...`. Збережіть його й нікому не показуйте.

### 2. Запустити бота на сервері
Бот має працювати цілодобово, тому його запускають на сервері, а не на телефоні.

**Railway** (найпростіше, приблизно $5 на місяць):
1. Зареєструйтесь на railway.com через GitHub.
2. New Project → Deploy from GitHub repo → оберіть цей репозиторій, у налаштуваннях сервісу вкажіть **Root Directory** `telegram-bot`.
3. У Variables додайте `BOT_TOKEN` = ваш токен.
4. Додайте Volume із шляхом `/data`, щоб записи не зникали після перезапуску.

**Або будь-який комп'ютер чи VPS, що працює постійно:**
```bash
cd telegram-bot
pip install -r requirements.txt
BOT_TOKEN=ваш_токен python bot.py
```
Або через Docker:
```bash
docker build -t diary-bot telegram-bot
docker run -d --restart=always -e BOT_TOKEN=ваш_токен -v diary-data:/data diary-bot
```

### 3. Створити групу
1. Створіть нову групу, додайте туди доньку.
2. У налаштуваннях групи увімкніть **Теми** (Topics).
3. Додайте бота в групу й зробіть **адміністратором** з правом «Керування темами».

### 4. Налаштувати
Напишіть у групі:
```
/setup
```
Бот створить 5 гілок. Потім задайте розклад:
```
/schedule
Пн
08:30-09:15 Математика
09:25-10:10 Українська мова
16:00-17:00 Танці
Вт
08:30-09:15 Англійська мова
```
Якщо потрібно, змініть інші налаштування:
```
/name Софійко            — як бот звертається до доньки
/habits                  — свій список звичок, кожна з нового рядка
/time ранок 07:30        — коли питати про настрій зранку (також «вечір» і «підсумок»)
/remind 10               — за скільки хвилин нагадувати про заняття
```

## Команди на щодень
- `/today`, `/yesterday`: підсумок дня
- `/next`: яке заняття наступне й через скільки
- `/week`, `/month`: графіки за тиждень чи місяць, розсилаються по гілках
- `/mood`, `/habits_today`: відмітити настрій чи звички будь-коли
- Оцінку можна додати й вручну: напишіть у гілку «Оцінки» `Математика 10`
- Коментар до заняття: дайте відповідь (Reply) на повідомлення «Як пройшло заняття…»

Записи зберігаються у файлі `diary.db` (SQLite) на сервері.
