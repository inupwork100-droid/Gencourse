## 3. Як швидко запустити (шпаргалка)

```bash
# 1. перейти в агента й активувати оточення
cd рілси/агент
python3 -m venv .venv && source .venv/bin/activate   # тільки перший раз
pip install -r requirements.txt                        # тільки перший раз

# 2. (перший раз) ключі — усі опційні
cp .env.example .env   # і вписати ключі, якщо є

# 3. зібрати рілс з прикладу
python3 main.py \
  --script examples/scenario_example.yaml \
  --library "../швидкі рілс" \
  --output out/result.mp4
```

Потрібен встановлений `ffmpeg`. Детальніше — у `рілси/агент/README.md`.
