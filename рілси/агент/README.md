# Агент створення рілсів

Бере текстовий сценарій, підбирає під кожну сцену відео/фото з вашої
бібліотеки (тека-тема), за потреби добирає резерв зі стокових API
(Pexels/Pixabay), додає озвучку (ElevenLabs) і склеює все в готовий
вертикальний mp4 (1080×1920) з випаленими субтитрами.

## Встановлення

```bash
cd рілси/агент
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # і впишіть свої API-ключі (усі необов'язкові)
```

Потрібен встановлений `ffmpeg` у системі.

## Формат сценарію

YAML-файл зі списком сцен. `tags` — ключові слова, за якими підбирається
відео/фото; `duration` — тривалість сцени в секундах.

```yaml
title: "Назва рілсу"
scenes:
  - text: "Текст сцени (субтитри + озвучка)"
    tags: [мотивація, ранок]
    duration: 3
```

Приклад: `examples/scenario_example.yaml`.

## Бібліотека медіа (тека-тема)

У кожній теці-темі (напр. `рілси/швидкі рілс/`) лежить `manifest.yaml` зі
списком файлів і тегів:

```yaml
assets:
  - file: clip_ranok.mp4
    type: video
    tags: [мотивація, ранок]
  - file: photo1.jpg
    type: image
    tags: [мотивація]
```

Файли (`clip_ranok.mp4`, `photo1.jpg` тощо) мають лежати поруч у тій же
теці. Агент шукає асет з найбільшим збігом тегів зі сценою.

## Запуск

```bash
python3 main.py \
  --script examples/scenario_example.yaml \
  --library "../швидкі рілс" \
  --output out/result.mp4
```

Прапорці:
- `--no-stock` — не звертатись до Pexels/Pixabay, навіть якщо ключі задані
- `--no-voiceover` — зібрати без озвучки (тільки субтитри)
- `--keep-temp` — не видаляти тимчасові файли (зручно для дебагу)

## Пріоритет джерела медіа для кожної сцени

1. Ваша бібліотека (`manifest.yaml` у теці теми)
2. Стокове відео/фото за тегами (Pexels → Pixabay), якщо задано API-ключ
3. Якщо нічого не знайдено — агент зупиняється з чіткою помилкою, яка
   сцена й теги не покриті

Агент **не** завантажує/скрапить контент з Instagram, TikTok чи YouTube —
це порушує умови користування цих сервісів і авторські права власників
відео. Для резервного контенту використовуються лише стокові сервіси з
ліцензією на комерційне використання.

## API-ключі

Усі — опційні, задаються в `.env`:

| Змінна | Навіщо |
|---|---|
| `PEXELS_API_KEY` | резервне стокове відео/фото |
| `PIXABAY_API_KEY` | резервне стокове відео/фото |
| `ELEVENLABS_API_KEY` + `ELEVENLABS_VOICE_ID` | озвучка тексту сценарію |
| `HEYGEN_API_KEY` | (заплановано) відео з вашим аватаром |

## Заплановано (наступні кроки)

- Інтеграція HeyGen: генерація відео, де аватар промовляє сценарій —
  або замінює частину відеоряду, або йде окремим шаром
- Автоматична музика/переходи, брендинг (лого, watermark)
- Точна синхронізація тривалості сцени з довжиною згенерованої озвучки
