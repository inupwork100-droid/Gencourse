# круглий баклажановий калькулятор

Робочий калькулятор круглої форми з кнопками-трикутниками.

## Як відкрити

Просто відкрий `index.html` у браузері (подвійний клік) — це один самодостатній файл
без залежностей.

## Дизайн (за задумом)

- **Форма** — кругла (тіло-коло).
- **Колір основи** — баклажановий (глибокий темно-фіолетовий).
- **Кнопки** — оксамитові (бархатні): плюшеві градієнти з м'яким відблиском.
- **Трикутники за парністю цифр:**
  - **парні** числа (`0, 2, 4, 6, 8`) — трикутники дивляться **вгору** ▲
  - **непарні** числа (`1, 3, 5, 7, 9`) — трикутники дивляться **вниз** ▼
- **Цифри та знаки відрізняються кольором:**
  - цифри — фіолетовий оксамит, світлий підпис;
  - знаки — золотисто-винний оксамит, `=` — найяскравіший.
- Цифри та знаки навмисно **стиснуті** (від'ємний letter-spacing).

Трикутники в кожному рядку «наїжджають» один на одного на пів-ширини й
переплітаються в мозаїку; шви між ними — того ж баклажанового кольору, що й основа.

## Можливості

- Дії: `+  −  ×  ÷`, `=`
- Десяткова крапка, відсоток `%`, зміна знаку `±`
- Очищення `C`, стирання останнього символу `⌫`
- Рядок виразу над результатом
- Керування з клавіатури: цифри, `+ - * /`, `Enter`/`=`, `Backspace`, `Esc`/`C`, `.`, `%`

## Технічно

Чистий HTML + CSS + ванільний JS. Трикутники зроблено через `clip-path`,
оксамит — багатошаровими `radial/linear-gradient`, парність цифр забезпечується
розкладкою у скрипті (з перевіркою в консолі).
